Cómo ejecutarlo

cd proyectos/pipeline-mqtt-grafana
docker compose up -d --build --wait
powershell -File .\verificar.ps1

Abre http://localhost:3000 y espera 1 a 2 minutos. Para borrar todo: docker compose down -v.

Decisiones y límites

  • Telegraf en vez de Node-RED para la ingesta: es declarativo, un solo archivo versionable y sin nodos que instalar.
  • Aprovisionamiento por archivos: la fuente de datos y el tablero se reconstruyen idénticos en cualquier equipo.
  • Arranque ordenado con healthchecks y service_healthy; los puertos quedan atados a 127.0.0.1.
  • Un mensaje que no es JSON válido se descarta y queda en el log de Telegraf (lo comprobé publicando uno con comillas perdidas).
  • Seguridad: es una pila de pruebas. El broker permite anónimos y sin TLS, y Grafana tiene visor anónimo: antes de exponerla hay que poner usuarios, TLS, ACL y claves propias (el README lo detalla).
  • Datos simulados: el hardware real (ESP32 y medidor) todavía no se probó; el mensaje de energía es el mismo que publica su firmware.
